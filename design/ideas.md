# アイディア集 ― 魔法・入手・マルチ・ボス

「面白い」を細かく分けて、それぞれを強める案。**実装済** と書いたものは、もうゲームに入っている。

## 1. 面白さの分解

| 面白さ | 何が気持ちいいか | 強める手段 |
|---|---|---|
| 唱える | 声に出した言葉が、そのまま形になる | 属性ごとに姿の違う魔弾、放つ瞬間の魔法陣(**実装済**) |
| 組む | 言霊の組み合わせで、自分だけの術ができる | 修飾の言霊を増やす: 連鎖・追尾・分裂(**実装済**) |
| 集める | 言霊が増えるほど、できることが広がる | 言霊に希少さの段差を付ける。属性は「秘奥」(**実装済**) |
| 読む | 敵の構えを見て、次の一手を決める | ボスが相手を見て技を変える(**実装済**) |
| 合わせる | 仲間と声・属性が噛み合った時に強い | 連携(**実装済**)、合唱(既存) |
| 知る | 魔物の姿に理由がある | 魔物の記録(**実装済**) |

## 2. 魔法の出し方

- **魔法の名で締める**(既存): 最後に「ファイア」などを唱えて完成。
- **名詠み**(既存): 熟練すると、名だけで全力。
- **溜め詠唱**(案): 詠唱文を唱え終えた後、名を呼ぶまで息を止めている間だけ威力が溜まる。声の「間」が技術になる。
- **輪唱**(案): 仲間が唱え終えた術の名を、2秒以内に別の仲間が復唱すると、同じ術が半分の威力でもう一度出る。
- **囁き**(案): 小さな声で唱えると、威力は落ちるが魔物に聞きつけられない。声の大きさを遊びにする。
- **逆さ詠唱**(案): 呪いで言霊の順が逆さになった時、逆順で唱え切ると 1.5 倍。災難を腕前で返す。

## 3. 魔法の形式(出し方の言霊)

既存: 穿槍・天雨・円環・刻印・城壁・衛星・付与。追加の修飾: **連鎖・追尾・分裂(実装済)**。

- **連鎖**: 当たると近くの敵へ飛び移る。雷でなくても連鎖する。
- **追尾**: 魔弾が近くの敵へ曲がる。動く的に強い。
- **分裂**: 三つに分かれて扇状に飛ぶ。一つあたりの威力は 0.6 倍。
- **奔流**(案): 唱えている間じゅう出続ける光線。声を伸ばすほど続く。
- **跳弾**(案): 壁で跳ね返る。狭い回廊で強い。
- **遅延**(案): 置いてから3秒後に発動。仲間の術と時間を合わせる。
- **反響**(案): 同じ術が、1秒遅れてもう一度出る(威力半分)。

## 4. 魔法の入手

希少さの段差(**実装済**):

| 段 | 言霊 | 手に入れ方 |
|---|---|---|
| ふつう | 出し方・効果・修飾 | 古文書(魔物・宝箱)。写本(欠片2 + 魔晶2)で種類を選んで綴れる |
| 貴重 | 秘伝書(属性の威力 +15%) | 宝箱。写本(欠片3 + 魔晶3 + 骨片2) |
| 秘奥 | 属性そのもの | 迷宮ではまず出ない。秘奥の写本(欠片6 + 魔晶4 + 鉄屑2)で、望んだ属性を綴る |

**言霊の欠片**(**実装済**)の出どころ: 守護者(三つ)、精鋭(一つ)、ふつうの魔物(ごく稀)、すでに覚えている古文書を読んで砕く(一つ)。

これから足せる入手の遊び:
- **聞き覚え**(案): 写本師や屍術師が唱えた詠唱を、3回聞くとその言霊を覚える。敵の声を聞く理由になる。
- **碑文**(案): 壁の言霊の帯(刻まれた文字)の前で、欠けた一語を正しく唱えると覚える。読み解きの遊び。
- **精霊の頼み**(既存)の報酬に、その精霊の言霊を。
- **交換**(案): 仲間と古文書を渡し合う(Gで落として拾う、は今もできる)。

## 5. マルチプレイの面白い要素

- **連携**(**実装済**): 別の魔導師が、違う属性で4秒以内に同じ敵へ当てると、傷が 1.25 倍。属性を散らすほど強い。
- **合唱**(既存): 声が重なると 2.2 倍。
- **清流 → 雷 / 氷**(既存): 片方が濡らし、片方が感電・氷結させる。
- **役割**(案): 得意属性の「第二の得手」を活かして、灯り役(炎)・癒し手(聖)・足止め(氷)・火力(闇)に自然と分かれる。
- **声の受け渡し**(案): 声を奪われた仲間(蝙蝠の呪いなど)の代わりに、別の仲間が名を呼んで術を完成させる。
- **二重封印**(案): 二人が別々の言霊を同時に唱えないと開かない扉。VC で息を合わせる。
- **囮**(案): 大声で唱えた者に魔物が集まる。仲間がその隙に長い詠唱を通す。

## 6. ボスの攻撃(**実装済**)

これまでは、決まった4つの技を順番に出すだけだった。今は相手を見て変える。

- **詠唱を聞いたら咆哮**: 近くで唱えていると、短い構えで吠えて詠唱を乱す。守護か距離で対処する。
- **背後へ回られたら薙ぎ払い**。
- **懐に入られたら叩きつけか噛みつき**、中距離なら噛みつきの突進で詰める。
- **立ち止まった者には星を落とす**。
- **同じ技を続けにくい**。
- **後半(体力半分以下)**: 構えの長さに緩急が付き、隙を見せずに次の技へつなぐ連続技が混じる。
- 新しい技: **噛み砕き**(突進)、**咆哮**(まわり全体・詠唱妨害)。

これから足せる案:
- 守護者ごとの固有技(氷冠巨人が鐘を鳴らして全員の足を鈍らせる、グリフォンが手紙を落として拾いに降りる隙、など)。
- 場を使う技(広間の柱を壊して瓦礫を降らせる)。
