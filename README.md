# 詠唱迷宮 ARCANA VOX

声で呪文を唱えて戦う、3D一人称のダンジョン探索ゲーム（協力 / PvP）。

## 起動
```
node server.js
```
Chrome / Edge で http://localhost:8080 を開く（依存パッケージなし。Three.js は CDN から読み込み）。

## 遊び方
- **V を押しながら唱える** → 離すと発動。**C** で常時詠唱（ハンズフリー）。**Enter** は仲間とのチャット（詠唱不可）
- 呪文 = [対象] [修飾] [属性…] [形] [効果…] [起句]。例: `紅蓮 穿槍 放て`、`同胞に 聖光 癒息 円環 放て`、`刻印 氷獄 放て`
- 言霊は全22語。最初は8語だけ知っていて、残りは迷宮の古文書から見つける。どの言霊も一度唱えると、その「真意」が魔導書に記される
- **Tab** 魔導書（言霊メモ / 呪文の研究と1〜4キーへの割当 / 調合）、**E** 拾う・転移、**5〜9** 道具

## マルチプレイ
ロビーで「オンライン」を選び、同じ合言葉を入れる。LAN内なら `http://<サーバーPCのIP>:8080`。
ほかのプレイヤーの詠唱は頭上に文字で出るうえ、WebRTC の近接VCで声としても聞こえ、距離と方向によって聞こえ方が変わる。
※ ブラウザの仕様上、マイク（音声認識・VC）が使えるのは localhost か https だけ。LAN内のほかのPCから使う場合は https トンネル（例: cloudflared）を通すこと。

持ち物は下の6枠のみ。1〜6で持ち替え、左クリックで使用・装備、Gで落とす。聖域の書見台でFを押すと、次回もその階層・位置から再開できます。ボスは探索の先の大扉に守られた広間にいて、入場後は討伐まで戻れません。詳しい仕様・調査・検証は [設計ノート](design/dragon-boss.md) を参照。
