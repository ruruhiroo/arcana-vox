# Steam で出すまでの手順

ゲーム側の準備(Steam 用の書き出し、実績のつなぎ込み、アイコン、アップロード用の設定ファイル)は済んでいます。
残りは、Steamworks のアカウントで本人がする作業です。

## 1. 本人がすること(お金と登録)

1. **Steamworks に登録する**: https://partner.steamgames.com/
   - 本人確認、税の情報(日本在住なら W-8BEN)、振込先の銀行口座を入れる。
2. **Steam Direct の登録料を払う**: 1作品につき 100米ドル。
   - 売上が 1,000米ドルを超えると、登録料は戻ってくる。
3. **App ID をもらう**: 払うと App ID(数字)と Depot ID が発行される。
4. 発売の **30日以上前** にストアページを「近日登場」で公開し、ウィッシュリストを集める。
   - 登録料を払ってから発売できるまで、最低 30 日かかる。

## 2. Steam 用に書き出す

```bash
npm run dist:steam
```

- `dist/win-unpacked/` にフォルダごと書き出される。中の `ArcanaVox.exe` が起動ファイル。
- Steam はインストーラーではなく、このフォルダをそのまま配る。
- いつもの `npm run dist` は、Steam 以外で配る用の exe 1つ(ポータブル)。

## 3. 実績をつなぐ

ゲームの中には、実績を解除する場所がもう入っています。Steam 側でも同じ名前(API名)で実績を作ってください。

| API名 | 名前(例) | 解除される時 |
|---|---|---|
| FIRST_SPELL | 最初の詠唱 | はじめて術を放った |
| EUPHONY | 名詠 | 名詠(完唱・語順・結句)を決めた |
| CHORUS | 合唱詠唱 | 仲間と声を重ねて術を放った |
| NAME_CAST | 詠唱省略 | 熟練して、魔法の名だけで術を放った |
| MASTER | 化身 | ある属性で終の階梯(〇〇の化身)に至った |
| OOPS | 誤射 | 味方に術を当ててしまった |
| BOSS | 主を討つ | 層の主を倒した |
| FLOOR_3 / FLOOR_6 / FLOOR_10 | 第3層 / 第6層 / 第10層 | その層にたどり着いた |
| CLEAR | 迷宮踏破 | 『原初の魔導書』を手にした |
| WIPE | 全滅 | 全滅して、すべてを失った |

Steam の機能(実績・オーバーレイ)を有効にするには、一度だけ次を入れます。

```bash
npm i steamworks.js
```

- 入れていない時や、Steam を通さずに起動した時は、連携しないで普通に動きます。
- 開発中に試す時は、プロジェクトの一番上に `steam_appid.txt` を作り、App ID の数字だけを書く。
  - App ID が無いうちは、Valve のテスト用の `480` で試せる。
  - このファイルは配るフォルダには入れない(`depot_build.vdf` で除外してある)。

## 4. アップロードする(SteamPipe)

1. Steamworks の SDK から `steamcmd` を用意する。
2. `steam/app_build.vdf` の `0000000` を App ID に、`0000001` を Depot ID に書き換える。
   - `steam/depot_build.vdf` の `0000001` も Depot ID に書き換える。
3. 書き出してからアップロードする。

```bash
npm run dist:steam
```

```bash
steamcmd +login あなたのSteamworksアカウント +run_app_build "%CD%\steam\app_build.vdf" +quit
```

4. Steamworks の「SteamPipe → ビルド」で、上げたビルドを default ブランチに設定する。
5. 「インストール → 一般」で起動オプションを設定する: 実行ファイル `ArcanaVox.exe`、OS は Windows。

### 文章(下書き)

**短い説明(日本語)**
> 声に出して呪文を唱える、協力ダンジョン探索。言霊を組み合わせて自分だけの呪文を編み、仲間と声を重ねて迷宮の奥へ。全滅すれば、魔導書はすべて白紙に戻る。

**Short description (English)**
> A co-op dungeon crawler where you cast spells by speaking them aloud. Combine words of power into your own incantations, chant in chorus with friends, and dive deeper. Wipe out, and your grimoire is wiped clean.

**詳しい説明(日本語)**
- **声で唱える魔法**: マイクに向かって詠唱文を読み上げると術が発動する。言い淀めば術は弱まり、唱え切れば強くなる。
- **自分だけの呪文**: 迷宮で拾った言霊を組み合わせ、魔導書に呪文を書き記す。対象・属性・出し方・修飾の組み合わせで、術の形が変わる。
- **仲間と騒ぐ**: ネット越しの協力プレイ。近くの仲間の声だけが聞こえるボイスチャット。声を重ねる「合唱詠唱」で威力が跳ね上がる。味方に術を当てると、声が甲高くなったり、ロボット声になったりする。
- **毎回変わる迷宮**: 入るたびに形を変える迷宮。隠し部屋、謎の石板、凍りついた宝箱、層の主。
- **全滅で全ロス**: 覚えた言霊も、書いた呪文も、装備も、全滅すればすべて失う。

### 審査の前に確かめること

- **年齢区分**: コンテンツ調査に答える(暴力表現は軽度のファンタジー)。
- **マイク**: 使わない人のために、文字詠唱(Enter)でも遊べることをストアに書く。
- **ネット**: オンラインのマルチプレイは P2P。ひとりならネット無しで遊べる。
- **ファイアウォール**: 同じ LAN で遊ぶためにゲームの中でサーバーを開くので、初回起動時に Windows のファイアウォールの確認が出ることがある。
- **価格**: 決めておく(地域ごとの価格は Steam が提案してくれる)。
