# 詠唱迷宮 ARCANA VOX

声に出して呪文を唱えて戦う、3D 一人称の迷宮探索ゲーム（協力 / PvP）。

## 遊ぶ
1. [Releases](https://github.com/ruruhiroo/arcana-vox/releases/latest) を開く
2. 「Assets」の中の `ArcanaVox-〇.〇.〇.exe` をダウンロードする（「Source code」は不要）
3. ダブルクリックで起動する（インストール不要・Windows）
4. 「Windows によって PC が保護されました」と出たら「詳細情報 → 実行」

マイクを使う。最初にマイクの使用を許可すること。

## 操作
| 操作 | キー |
|---|---|
| 詠唱する | **V** を押しながら唱え、離すと発動（**C** で押さなくても聞き取る） |
| 移動 / 視点 | WASD / マウス（**Shift** で走る、**Space** で跳ぶ） |
| 魔導書を顔の前に掲げて読む | 右クリック |
| 調べる・拾う・扉を開ける | **F** |
| 魔導書（呪文を書く・言霊・調合・魔物の記録） | **Tab** |
| 魔導書の頁をめくる | **Z** / **X**（またはホイール） |
| 持ち物を持ち替える / 使う / 落とす | **1〜6** / 左クリック / **G** |
| 装備と能力 | **E** |
| 仲間に文字で話す | **Enter** |
| 休息（記録・設定） | **Esc** |

キーは「Esc → 設定 → キー割り当て」で変えられる。

## 呪文の組み立て
言霊を「対象 → 修飾 → 属性 → 出し方」の順に唱え、最後に魔法の名で締める。

- 例: 「汝に 紅蓮 穿槍 ― ファイア」
- 魔導書（Tab）に自分の呪文を書いておくと、開いた頁の詠唱文がそのまま手元の本に出る
- 言霊は最初は少しだけ知っていて、残りは迷宮の古文書を読んで覚える

## マルチプレイ
タイトル画面の「接続」で選ぶ。

- **ネット: 部屋を作る** … 出てきた部屋コードを仲間に伝える
- **ネット: 部屋に入る** … 教わった部屋コードを入れる
- **LAN: 直接接続** … 同じ家の中などで、下の「自分のPCで動かす」を使っている時

近くの仲間の声はボイスチャットで聞こえ、距離と向きで聞こえ方が変わる。

## 自分のPCで動かす（開発する人向け）
Node.js が要る。

```
git clone https://github.com/ruruhiroo/arcana-vox.git
cd arcana-vox
npm install
npm start          # アプリとして起動する
```

確かめる時だけブラウザで動かしたい場合は `node server.js` を実行して http://localhost:8080 を開く。

| やること | コマンド |
|---|---|
| テスト | `npm test` |
| Windows の exe を作る | `npm run dist` |

`v0.4.0` のようなタグを push すると、GitHub が exe を作って Releases に載せる。
